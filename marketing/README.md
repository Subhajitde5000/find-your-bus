# Pathsathi — Kolkata Bus Marketing Kit
### Find Your Bus Campaign

This folder is the launch kit for **Pathsathi — Kolkata bus times** on Instagram, Facebook, YouTube,
WhatsApp, X and Reddit. Start with [`30-day-plan.md`](30-day-plan.md); it links to everything else.

**Brand:** Pathsathi (পথসাথী) — Kolkata bus times  
**Tagline:** _Find your bus in 10 seconds. Ride offline. No signal needed._  
**Website:** static PWA — the Kolkata bus timetable plus the offline ride screen, at `{{SITE}}`  
**Core offer:** 
- 651 routes, 2,194 stops, 193 stands
- Search any 2 stops → See every direct bus + 1-change options
- "Set on Bus" offline ride screen — GPS follows YOU, no signal needed, tells you “You are not seated in this bus” if off-route
- 100% free, no login, works as installable PWA (2.8 MB)

**Start date:** five pre-launch days (P1–P5), then Day 1 = launch on a Monday morning. All times are
IST. Posting windows used in the plan: 08:30 (the commute), 13:00 (lunch), 20:00 (evening scroll).
