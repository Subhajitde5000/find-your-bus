# Cholo — Kolkata Bus Marketing Kit v2
### Find Your Bus + Offline Map + QR Campaign — 0₹ Guerrilla Edition

This folder has everything to launch **Cholo — Kolkata Bus Timetables v2** on Instagram, Facebook, X, YouTube Shorts + WhatsApp + Street.

**Brand:** Cholo (চলো) — Kolkata Bus Timetables
**Tagline:** _Find Your Bus in 10s. Ride Offline. Scan QR. No Signal Needed — Hooghly to Salt Lake._
**Site:** Static PWA 2.8MB + Native Android/iOS apps · No login · No ads
**Core Offer v2:**
- 651 routes · 193 stands · 2194 stops · 24,777 timed runs · 1731 stops with GPS
- Search any 2 stops → direct buses + 1-change, shareable `?from=&to=&time=` links, Recently Viewed
- “Set on Bus” offline ride — GPS along real roads (72KB), distance+time to every ahead stop, alerts (Get ready / Next / Passed / Wrong direction + buzz), says “You are not seated in this bus”
- **All-Stops Map `/map`** — 1731 stops on offline vector map + Hooghly, canals, 101 lakes, 28 station footprints, 491 landmarks, day/night/auto, nearest-stop, tap stop→buses, roads toggle
- **QR Stickers** — On-bus `/on-bus?route=1` (identifies bus via GPS+clock, countdown to destination) + At-stop `/stop?stop=Esplanade` (Next + Whole day hour-by-hour) + `/scan` (ML Kit offline + jsQR fallback + paste link)
- Typo-tolerant + Bengali aliases (হাওড়া, ধর্মতলা, সল্টলেক, শিয়ালদহ) · Community Desk (Report bus / Suggest feature, no login)

**Posting windows IST:** 8:30 AM (Esplanade rush) · 1 PM (College Street lunch) · 7:30 PM (Garia scroll)
**Budget:** ₹0 — every post has offline guerrilla twin (QR print at library, FB group value comment, WhatsApp forward, college ambassador)
