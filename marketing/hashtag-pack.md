# Pathsathi — Hashtag Pack

**How to use this file:** every post in [`30-day-plan.md`](30-day-plan.md) names a **set** (Set A,
Set B, …). Copy that set, add **one** local tag for the stop or area in the post, and paste it at the
bottom of the caption. Do not invent new tags on the day; that is how accounts end up with 30
hashtags nobody searches.

Related: [`30-day-plan.md`](30-day-plan.md) (all 30 days + pre-launch) · [`shorts-scripts.md`](shorts-scripts.md) (video scripts).

---

## 1. How hashtags actually work now (read once, then forget)

- Hashtags are **a filing label, not a growth trick.** Instagram search reads your caption, your
  on-screen text and your audio; a pile of tags does not make a Reel travel.
- What actually decides reach: the **first 2 seconds**, **watch time**, **saves**, **sends to a
  friend**, and whether the viewer is in Kolkata. All four are things a hashtag cannot fix.
- So: **use few, use local, use the same brand tag every time.** That way the brand tag becomes a
  place a curious person can click and see everything you have made.
- **Never repeat the exact same block on every post.** Rotate the local tags (§6) so Instagram does
  not read the caption as boilerplate.

**How many, per platform**

| Platform | How many | Where | Why |
|---|---|---|---|
| Instagram feed / carousel / Reel | **5–8** | end of the caption | enough to file it, few enough to read |
| Facebook Page post | **2–3** | end of the caption | FB search is weak; tags mostly decorate |
| Facebook group post | **0–2** | end, or none | group admins remove posts that look like ads |
| YouTube Shorts | **3** in the description + the title carries the words | first line of the description | YT uses the words, not the tag wall |
| X | **1–2** | inside the sentence, not a block at the end | looks like a person, not a bot |
| WhatsApp channel / status | **0** | — | tags look like spam in a chat |
| Reddit | **0** | — | hashtags are downvoted there |
| Telegram | **0** | — | same |

**Choose the tag from the post, not from a list:** whichever stop the post is about
(`/stop?stop=Esplanade` → `#Esplanade`). One tag, the biggest one that is still true.

**Bengali tags** (optional, mix at most one in):
```
#কলকাতা #কলকাতারবাস #পথসাথী #বাস
```

Search in Kolkata is mixed Bengali and English, and English tags carry most of the volume — so
Bengali is for warmth, not for reach.

## 6. Rotation rules

1. **Every post gets a different local tag** — that alone keeps captions from looking copied.
2. **Brand tag stays.** `#Pathsathi` on everything, followed, so your grid is one click away.
3. **Never more than 8 on Instagram, never more than 2 on X.**
4. **Never put the same block in the first comment and the caption.** Pick one place — the caption.
5. **Stories: no hashtags.** Use a location sticker (the actual stop or area) instead; it reaches
   people nearby, which is exactly who you want.

---

## 7. Do not use

| Tag or habit | Why |
|---|---|
| `#followforfollow`, `#l4l`, `#f4f`, `#followme` | bot signal; invites spam followers who never install |
| `#viral`, `#fyp`, `#trending`, `#explorepage`, `#reels`, `#reelsindia` | zero targeting value; wastes space you could give a local tag |
| `#instagood`, `#photooftheday`, `#likeforlikes` | generic; tells the algorithm nothing about a bus app |
| Any tag that is not true about the post | misclassification; worse reach than no tag |
| Tagging 30 tags including 22 unrelated ones | reads as spam, and Instagram's own guidance says fewer, relevant tags |
| Tagging a celebrity or a rival app's name | reports and shadow-limits |

**One exception to "avoid generic":** `#Kolkata` is generic *and* correct — it is the single most
searched tag your audience uses, so keep it in most sets.
