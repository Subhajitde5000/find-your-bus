▣ konbus.QR STICKER MAKER
Private · never deploy this folder

Make a sticker

One QR for a bus, one for a bus stop. The code holds a plain https link, so it opens the app where the app is installed and the website everywhere else.

    Pick a route on the left

    The sticker for that bus appears here, with the link inside it, a PNG and an SVG.

    —

    Today the stickers name the route only, and the app works out which bus from your location and the timetable. If you later print a sticker for one physical bus, put its number here and the link will carry it.

      Sticker size

      Print at 100% (no “fit to page”), on sticker paper or plain paper with tape. Each sticker is 90 × 60 mm with a 40 mm code. Stickers always print black on white, whatever theme this screen is in.

      Keep this folder private. It is not part of the website build: it lives outside fontend/, has no route on the site, and must never be uploaded to the public server. Open it by double-clicking index.html.

      The catalogue (routes and stops) was generated from the website's own data on —. Re-run node qr-admin/scripts/build-catalog.mjs after a data update.

      QR encoding: qrcode-generator by Kazuhiko Arase, MIT licence, vendored in vendor/qrcode.js.
