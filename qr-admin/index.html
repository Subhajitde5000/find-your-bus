One sticker per route. The screen it opens asks for a position once, finds the nearest stop of that route and matches the clock against the timetable to work out which bus it is.

Leave direction, registration and stops blank for the ordinary route sticker. The registration field is for the per-bus stickers planned later — today the screen shows it as printed and still identifies the bus from the timetable.

One sticker per stop. It opens that stop’s board: the next two hours first, with the rest of the day and the whole day a tap away. Both directions are shown, each labelled with its terminus.

Private. This page is not part of the website build and is never linked from it. Keep it on your own computer, or behind a password on a host you control — never in the public web root, and never committed to a public deploy.

Links must match the domain. Android App Links and iOS Universal Links only work when the printed domain holds the verification files (/.well-known/assetlinks.json and /.well-known/apple-app-site-association) that the build writes from APP_LINK_HOST. Read qr-admin/README.md before printing a batch.
