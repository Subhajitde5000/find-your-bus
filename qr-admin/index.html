Print the stickers

One QR for every bus route (on bus), one for every bus stop (at bus stop). Each code is a plain link to this site’s /qr/… screens: a phone with the app opens the app, a phone without it opens the website. Nothing is uploaded from this page — it builds links and draws the QR codes in your browser, from the timetable data bundled beside it.

On bus sticker

One sticker per route. The screen it opens asks for a position once, finds the nearest stop of that route and matches the clock against the timetable to work out which bus it is.

Leave direction, registration and stops blank for the ordinary route sticker. The registration field exists for the per-bus stickers planned later — today the screen shows it as printed and still identifies the bus from the timetable.

At bus stop sticker

One sticker per stop. It opens that stop’s board: the next two hours first, with the whole day one tap away. Both directions are shown, each labelled with the terminus it heads to.
